# 大学生垂直社区产品与规模路线

## 当前产品定位

嘉大圈不是通用论坛换皮，而是嘉兴大学学生自己的实名校园社区：课程学业、实习就业、校园生活、经验问答、社团活动和闲置交易形成内容闭环。当前只服务学生，审核员与管理员负责平台治理，教师和学校部门身份留到产品验证后再评估。

当前版本已经具备：

- 校园广场、板块、标签、搜索、推荐/最新/热门信息流；
- 关注用户和“我的关注”信息流；
- 图文发帖、评论、楼中楼、点赞、收藏、匿名表达；
- 校园邮箱验证和验证后互动门槛；
- 站内私信，减少公开校外联系方式的需求；
- 规则 + 可选真实 LLM 初审、人工复核、举报和审计日志；
- 学生社区热榜、热门话题与活跃同学；
- 审核员/管理员后台、封禁、板块和精选运营。

## 对标层级

### NodeLoc/成熟独立论坛层级

功能形态已经接近完整社区产品。继续补齐部署监控、备份恢复、运营规则、内容冷启动和真实学校身份源后，可以作为一所学校或一个大学生圈层的正式论坛运营。

### 知乎/贴吧的产品体验层级

可以逐步做到相似的内容消费体验，但必须保持大学生垂直差异：

- 话题关注、校园榜单、课程/专业知识库；
- 高质量回答排序、采纳与经验沉淀；
- 同校、同学院、同年级的可控推荐；
- 新生、考研、实习、毕业季等生命周期运营；
- 社团主页、活动报名、校内二手交易信用；
- 校内活动报名和闲置交易信用。

### 知乎/贴吧的流量规模层级

不能仅靠前端页面或单机数据库“做到”。它需要持续的产品、审核、推荐算法、SRE、法务与校园运营团队，以及分布式基础设施。建议先验证单校活跃和留存，再扩展多校，而不是提前建设超大规模架构。

## 推荐里程碑

1. 单校内测：100–500 名嘉大学生种子用户，验证发帖率、次日留存、优质内容供给和举报处理时效。
2. 单校正式运营：接学校统一身份/邮箱，配置真实邮件与 LLM，完成备案、隐私政策、备份与监控。
3. 多校试点：引入 campus tenant、校园管理员、对象存储、PostgreSQL、Redis 与全文检索。
4. 区域扩展：推荐系统、反作弊、内容分发、审核队列和数据分析平台服务化。
